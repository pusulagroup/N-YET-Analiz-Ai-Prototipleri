# NİYET V7 — Luna sürümü

- Varsayılan model: `gpt-5.6-luna`
- Özel sohbet yanıtları OpenAI API üzerinden üretilir.
- Yeni paylaşım ön analizi OpenAI API üzerinden yapılır.
- Kullanıcının yorumları API tarafından yapılandırılmış iletişim sinyallerine ayrılır; 5 ana skoru uygulamanın kendi formülleri düşürür.
- Botların akış yorumları ve kullanıcıya yanıtları API üzerinden üretilir. Yerel `topicResponse/botReply` cevabı yoktur.
- Tartışma Isısı API sinyallerinden NİYET formülüyle güncellenir.
- `videos/` klasöründe 25 adet yaklaşık 30 saniyelik mikro eğitim videosu hazırdır.
- Eğitim videoları sessiz, metin tabanlı prototip içerikleridir; internet gerektirmez.

Windows: `V7_BASLAT_WINDOWS.bat`
Mac/Linux: `V7_BASLAT_MAC_LINUX.command`
