# NİYET V13.5

- NİYET Algı Analizi API akışı sohbet/yorum API akışından ayrıştırılarak sağlamlaştırıldı.
- Algı Kararlılığı ve Minimum Müdahale ikinci çıkarımları 4'lü küçük gruplara bölündü.
- Bir varyant/öneri API isteğinin başarısız olması artık ana insan-kalibre analizi yerel moda düşürmüyor.
- Başarısız varyant grupları tek tek yeniden deneniyor.
- Ana analiz ve öneri üretimi için yapılandırılmış çıktı token sınırları yükseltildi.
- Model tabanlı öneri üretimi geçici olarak aksarsa deterministik minimal adaylarla devam ediliyor.
- Sürüm adı V13.5 olarak sadeleştirildi.
