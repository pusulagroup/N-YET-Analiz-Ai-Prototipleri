# NİYET — VYARISMA

TEKNOFEST sunumu için dondurulmuş yarışma sürümüdür.

## Korunan çekirdek
- Niyet–Algı Uyumu
- Yanlış Anlaşılma Riski
- Tartışma Çıkarma Riski
- İfade Önerisi ve Diğer Olası Algılar
- Tartışma Isısı ve Sohbet Sağlığı
- NİYET Skoru
- Yaşa duyarlı kullanım
- 25 mikro gelişim videosu + 25 uygulama sorusu
- İnsan algısı kalibrasyon katmanı

## Son stabilizasyon
- Birleşik günlük dil ifadeleri genişletildi.
- Günlük dil ile gerçekten yetersiz/kısa metin ayrıldı.
- Mobil tarayıcı yakınlaştırma engeli kaldırıldı.
- Skor radar grafiği dar ekranlarda responsive hale getirildi.
- Kullanıcıya görünen eski sürüm etiketleri temizlendi.
- API durumu daha doğru biçimde 'yapılandırıldı / yapılandırılmadı' olarak gösteriliyor.
- Gunicorn timeout değeri 240 saniyeye çıkarıldı.
- Çalışan Flask/Werkzeug video sistemi korunmuştur.

Bu sürümden sonra yeni özellik eklenmemesi, yalnızca kritik hata varsa müdahale edilmesi önerilir.
